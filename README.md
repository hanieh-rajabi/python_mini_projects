# Number Guessing Game 🎯

A simple and fun Python game where the player tries to guess a randomly generated number. This project is perfect for beginners to practice Python programming concepts such as loops, conditionals, and user input.

---

## **Features**

1. The game generates a random number within a specified range (default: 1 to 100).  
2. The player is prompted to guess the number.  
3. For each incorrect guess, the game provides a hint: whether the number is higher or lower than the guess.  
4. Each incorrect guess reduces the player’s score.  
5. The game ends when the player correctly guesses the number or chooses to quit.
